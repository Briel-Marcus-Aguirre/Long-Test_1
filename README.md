# Books Per Box

## Description

This program calculates how many books go in a box based on the users input and if there is a remainder it goes in a loose pack

## How to Run
1. Open the program file in VS Code, Replit, or Google Colab.
2. Run the program.
3. Enter the values for Total_Books andBooks_per_Box
4. Check the answer displayed on the screen

## Input Needed
-Total_Books
-Books_per_Box

## Sample Output
What are the total No. of Books? 27
How many books fit in 1 box? 5
There will be 5 filled boxes and 2 loose packs.
